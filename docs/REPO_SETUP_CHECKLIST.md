# Repository Setup Checklist

After creating and cloning the empty GitHub repository:

```bash
unzip fjordpulse_complete_skeleton.zip -d fjordpulse
cd fjordpulse
make verify-planning
git add .
git commit -m "Add consolidated FjordPulse implementation skeleton"
```

Then start Codex from the repository root. Ensure it reads `AGENTS.md`, then submit `GOAL.md` as the implementation goal.

No additional ZIPs or overlays are required.
